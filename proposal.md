# Random Basketball Game

## Repository
https://github.com/dal673219/Vo-s-Final-Project.git

## Description
A simple basketball game where the player inputs a power and angle to shoot a ball into the basket for points. The ball can vary such as tennis balls, footballs, or magical balls.

## Features
- Feature 1 - A random order of balls with varying reactions to being thrown
    -  Executed with random.py and class functions to store the varying objects
- Feature 2 - colorful effects and particles
    - pygame draw and particle learned from rain lab

## Challenges
- learning and coding object interactions with obstacles
- learning and coding object ball physics
- learning and coding an object being thrown in an arch
- learning and coding visual game effects

## Outcomes
Ideal Outcomes:
- A complexly coded game that take varying random components to input and calculate an object's physics into being thrown into a goal.

Minimal Viable Outcome:
- A basketball game that shows design creativity and randomability.
